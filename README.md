# Superstore Data Analysis Project

## Objective
Analyze the Superstore dataset using Pandas to extract insights and visualize trends.

---

## Dataset
- Source: Kaggle Superstore Dataset
- Contains sales, profit, customer, and regional data

---

## Tasks Performed
- Data Loading & Exploration
- Data Cleaning
- Feature Engineering
- GroupBy & Aggregation
- Pivot Tables
- Data Splitting & Merging
- Data Visualization

---

## Key Insights
- Technology is the most profitable category
- Some regions generate high sales but low profit
- Discounts reduce profitability
- Sales show seasonal trends

---

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

---

## How to Run
1. Open the notebook
2. Make sure the dataset is in the same folder
3. Run all cells
